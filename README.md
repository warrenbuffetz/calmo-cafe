# Calmo Cafe

A responsive landing page for **Calmo** — a breakfast café blending retro-diner warmth with modern pastry-shop elegance.

## Brand

Colors and typography follow the Calmo brand guide:

| Token | Hex |
|-------|-----|
| Calmo Beige | `#F3EED7` |
| Calmo Blue | `#A2B9DB` |
| Calmo Burnt Brown | `#321B0F` |
| Calmo Red Brown | `#923F24` |

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

- Next.js (App Router)
- Tailwind CSS v4
- Lucide React
